# SubCraft v0.2.3

### 下载

| 文件 | 说明 |
|---|---|
| `SubCraft-0.2.3-win-x64.zip` / `SubCraft-0.2.3-portable.exe` | Windows 桌面版，解压即用 |
| `SubCraft-0.2.3-x64-linux.tar.gz` | Linux 桌面版（需 python3 与 ffmpeg） |
| `SubCraft-CLI-0.2.3-win-x64.zip` | **新** Windows 纯命令行版（CLI + MCP），约 71 MB |
| `SubCraft-CLI-0.2.3-linux-x64.tar.xz` | **新** Linux 纯命令行版（CLI + MCP），约 57 MB |

### 更新
- 新增纯命令行版：不含桌面界面，`subcraft <命令>` 直接用，`subcraft mcp` 启动 MCP 服务；运行时不往临时目录解压文件。
- 便携模式：在 `subcraft` 旁新建 `data` 文件夹，配置、缓存和 Whisper 模型都放在里面，删掉即清理干净。
- 修复 Windows 非 UTF-8 环境下 `mcp_server.py --list-tools` 中文输出报错。
- README 精简。

纯命令行版只用 CPU 识别；Windows 首次使用会自动下载 ffmpeg，Linux 请 `sudo apt install ffmpeg`。
