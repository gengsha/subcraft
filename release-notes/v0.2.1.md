# SubCraft v0.2.1

视频语音识别、AI 多厂商翻译、双语排版与字幕制作工具。

### 资产下载 (Downloads)

| 平台 | 文件名 | 说明 |
|---|---|---|
| **Windows x64** | `SubCraft-0.2.1-win-x64.zip` | 便携免安装版（内置 Python 独立后端与 ffmpeg 运行时，解压即用） |
| **Windows x64** | `SubCraft-0.2.1-portable.exe` | 单文件便携运行版 |
| **Linux x64** | `SubCraft-0.2.1-x64-linux.tar.gz` | Linux 独立安装包（解压后依赖系统 python3 与 ffmpeg） |

#### v0.2.1 更新说明：
- 修复：MCP `subcraft_load_subtitle_file` 以译文轨载入字幕文件时未套用副语言样式，双语 ASS 主副字幕字号相同；现与翻译生成的译文轨一致（0.7 倍字号 + 淡黄），设为主轨后主字幕更大。
- 发布流程自动化：推送 `v*` tag 后由 GitHub Actions 自动打包 Windows / Linux 并上传 Release，Windows 包发布前会对打包后的后端做启动与令牌校验冒烟测试。

#### Windows 使用提示：
下载后解压到任意目录，双击运行 `SubCraft.exe` 即可使用。首次使用本地语音识别时，将自动按需下载 Whisper 模型权重。

#### Linux 使用提示：
```bash
tar -xzf SubCraft-0.2.1-x64-linux.tar.gz
cd SubCraft-0.2.1-x64-linux
sudo apt update && sudo apt install -y ffmpeg python3 python3-pip
python3 -m pip install -r resources/backend/requirements.txt
./subcraft-app
```

完整功能介绍见 [README](https://github.com/gengsha/subcraft#readme)，上一版本说明见 [v0.2.0](https://github.com/gengsha/subcraft/releases/tag/v0.2.0)。
