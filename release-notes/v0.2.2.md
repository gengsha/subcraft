# SubCraft v0.2.2

视频语音识别、AI 多厂商翻译、双语排版与字幕制作工具。

### 资产下载 (Downloads)

| 平台 | 文件名 | 说明 |
|---|---|---|
| **Windows x64** | `SubCraft-0.2.2-win-x64.zip` | 便携免安装版（内置 Python 独立后端与 ffmpeg 运行时，解压即用） |
| **Windows x64** | `SubCraft-0.2.2-portable.exe` | 单文件便携运行版 |
| **Linux x64** | `SubCraft-0.2.2-x64-linux.tar.gz` | Linux 独立安装包（解压后依赖系统 python3 与 ffmpeg） |

#### v0.2.2 更新说明：
- 新增**批量处理**：CLI `batch` 与 MCP `subcraft_batch_process` 一次处理整个文件夹（课程、剧集），逐个执行「识别 →（可选）贴齐镜头切点 →（可选）翻译 → 导出字幕 / 成片」。
- **按集号自然排序**（EP2 排在 EP10 前），整批只加载一次识别模型。
- **断点续跑**：重跑自动跳过已完成的文件；单集失败只记进报告、不影响其余集数（`--stop-on-error` 可改为立即停止），结束后在输出目录写 `subcraft_batch_report.json`。
- `--split-cuts`：贴齐镜头切点后自动拆开仍跨镜头的字幕，且在翻译前完成，译文轨自然同步。
- `--subs`：批量翻译文件夹里已有的字幕文件（同名视频自动关联）。
- 支持 `--recursive` 递归子目录（输出保留目录结构）、`--pattern` 按文件名过滤、`--dry-run` 先看要处理哪些文件、`--limit` 限量试跑、`--force` 全部重做。
- MCP 工具增至 **28 个**；README 顶部加入完整流程演示 GIF。

#### Windows 使用提示：
下载后解压到任意目录，双击运行 `SubCraft.exe` 即可使用。首次使用本地语音识别时，将自动按需下载 Whisper 模型权重。

#### Linux 使用提示：
```bash
tar -xzf SubCraft-0.2.2-x64-linux.tar.gz
cd SubCraft-0.2.2-x64-linux
sudo apt update && sudo apt install -y ffmpeg python3 python3-pip
python3 -m pip install -r resources/backend/requirements.txt
./subcraft-app
```

完整功能介绍见 [README](https://github.com/gengsha/subcraft#readme)，上一版本说明见 [v0.2.1](https://github.com/gengsha/subcraft/releases/tag/v0.2.1)。
